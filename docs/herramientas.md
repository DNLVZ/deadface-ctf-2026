# Herramientas y uso documentado

[Inicio](../README.md)

| Herramienta | Evidencia y uso conservados |
| --- | --- |
| Python 3 | Scripts para ZIP, IPA, APK, Base64, JSON, SQLite, XOR y bytes. |
| PowerShell y C# integrado | Scripts de PCAP, TLS/SRTP y búsqueda de cadenas de memoria. |
| 7-Zip / 7zr | Extractor portable conservado para contenedores. |
| Capstone | Dependencia de análisis estático presente en las sesiones. |
| iced-x86 | Paquetes y salidas de desensamblado x86 conservados. |
| pngjs y Pillow | Lectura de imágenes y metadatos; Pillow utilizado en la revisión de la bitácora. |
| steghide | Prueba registrada con contraseña vacía en The Mark, sin resultado final. |
| Navegador y DevTools | HTML, recursos, comentarios y sitios del escenario. |
| Wireshark | Los filtros de las fichas permiten revisar los PCAP; la edición original no verificó su instalación local. |
| ExifTool y JADX | Alternativas didácticas. Su mención no acredita instalación o uso durante el evento. |

Los ejecutables y dependencias de estas herramientas no forman parte del repositorio. Los scripts autocontenidos de esta publicación requieren únicamente la biblioteca estándar de Python.

Fuente: bitácora técnica personal, página 8.
